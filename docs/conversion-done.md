# Conversion funnel implementation

Implemented in `feature/public-site-conversion-funnel`:

- demo → own-decision bridge on the buyer homepage;
- four-stage low-risk pilot section in EN/UA/PL;
- direct localized decision-intake CTA;
- responsive styles for the new funnel sections;
- unit/e2e coverage for localization and CTA routing;
- privacy-safe analytics event contract (provider wiring intentionally separate);
- SEO/indexing release checklist and buyer/claims guardrails.

The branch deliberately does not add fabricated customer proof, pricing promises, free-pilot claims, or additional visual effects.
