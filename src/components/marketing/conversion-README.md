# Conversion components

`PilotPath` owns the buyer-facing low-risk pilot explanation.

`conversion-copy.ts` contains short localized bridge copy used by the homepage.

`funnel-events.ts` defines analytics event names only; no analytics provider is coupled to marketing components and no form content should be attached to those events.

Keep conversion copy localized in EN/UA/PL and keep technical Core content out of these buyer components.
